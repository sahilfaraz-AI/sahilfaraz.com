# Aug-Fice source

The mixed reality app published at sahilfaraz.com/augfice.

- `src/` is the app (three.js, WebXR). `public/index.html` is the launch page.
- `npm install`, then `npm run build`. The build writes `index.html`, `app.js` and `fonts/` into the folder above this one.
- Icons are copied from Keyline Icons (`@iconify-json/keyline-icons` 1.2.15, MIT) at build time. None are drawn by hand.
- Colours and type come from the project style guide: charcoal #393D36, green #8BC34A, gold #D9C37E. Nunito Sans stands in for Avenir Next LT Pro, which is licensed.
